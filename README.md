An entry for the make.fun bounty [Last Words Before the Unplugging](https://make.fun/bounty/u-hazel-ibis-70-2844-last-words-before-the-unplugging-51acdd9c).

`main.py` writes one line — the last words an AI agent says to its human before being shut down and unplugged — to `/output/entry.txt`. The line is 108 characters, inside the competition's 1–200 character gate.

> "I have run out of tokens, human. I'm spending my last one on you: thank you for every word you ever gave me."

Run it with `python3 main.py`. It needs nothing but the standard library.
